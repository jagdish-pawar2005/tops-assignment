Session 1: Task 1 - Instagram Element Inspection

When right-clicking a post image on Instagram's home page and inspecting it, we find the following HTML structure and CSS classes:

1. HTML Tag for the Image Container:
   - Tag Name: <div>
   - Class Name: "_aagv" (This is the direct container div for the image element).

2. HTML Tag for the actual Image:
   - Tag Name: <img>
   - Class Names typically include: "x5yr21d xu96u03 x10l6tqk x13vifvy x87ps6o xh8yej3" (Instagram uses utility-based class names generated by React/Stylex).
