Responsive Columns Demo

These columns stack vertically on screens smaller than 576px (col-12), and become side-by-side on larger screens (col-md-6).

Left Feature Column

This takes full width (12 grid slots) on mobile viewports, but adjusts to 6 slots (50% width) on medium screens or wider.

Right Feature Column

Just like the left column, this wraps below on mobile, creating a user-friendly stacked vertical list rather than getting cramped side-by-side.
